# HƯỚNG DẪN ĐĂNG PORTALVERSE LÊN GITHUB

1. Giải nén thư mục ZIP.
2. Đặt `index.html` ở root (cùng cấp với `assets/`, `styles.css`, `portal-glyphs.js`).
3. GitHub > repository > Add file > Upload files, upload toàn bộ nội dung, giữ nguyên cây thư mục.
4. GitHub > Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Các file .mp3 được public nếu website public.

**Đừng chỉ upload .zip hoặc tải thư mục cha thành thư mục con:** GitHub Pages cần nhìn thấy `index.html` tại root.
